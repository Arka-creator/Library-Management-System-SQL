## Library Management System (SQL) <PROJ-2>
-A SQL project built using MySQL to manage (books, members, book issues, and returns.)

## Features
- Create and manage library database
- Store book and member records
- Issue and return books
- Retrieve currently issued and returned books
- Find overdue books
- Aggregate and JOIN queries for data analysis

## Technologies Used
- SQL
- MySQL
- VS Code
